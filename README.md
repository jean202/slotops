# SlotOps

SlotOps is a space and resource reservation operations SaaS for small offline businesses.

## What It Solves

- Operators manage locations, reservable resources, schedules, blackout dates, and reservation rules.
- Customers reserve rooms, courts, studios, or equipment by date and time.
- Staff handle approvals, cancellations, usage status, and notifications from one admin console.

## Target Customers

- Study room operators
- Practice room operators
- Photo studio operators
- Sports court operators
- Meeting room and equipment rental teams

## Core Product Principles

- Resource reservation, not ticket sales
- Time-slot operations, not seat-based booking
- Operator workflow first
- Rebuilt from scratch with domain terms unrelated to event ticketing
